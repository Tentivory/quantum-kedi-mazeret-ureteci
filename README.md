# Quantum Kedi Mazeret Üreteci

## Resmi Bilimsel Dokümantasyon (Ciddi Versiyon)

Bu depo, modern fiziğin en büyük gizemlerinden biri olan "Neden işe geç kaldım?" sorusuna kuantum mekaniğiyle cevap verir. Schrödinger'in kedisi hem ölü hem diridir, dolayısıyla hem zamanında gelmiş hem geç kalmıştır. Gözlem yapana kadar mazeretiniz geçerlidir.

### Özellikler
- Gerçek kuantum rastgelelik (Python random modülü kullanır, ama kuantum gibi davranır)
- 6 farklı ultra bilimsel mazeret
- Kedi durumunu süperpozisyonda tutar
- Çalışır. Gerçekten. Deneyin.

### Kullanım
```bash
python mazeret.py
```

Örnek çıktı: "Heisenberg belirsizlik ilkesine göre konumumu ve momentumumu aynı anda bilemem. Dolayısıyla işe gelirken nerede olduğumu bilmiyordum."

### Uyarı
Bu mazeretleri işyerinde kullanmak sizi kovdurabilir. Sorumluluk tamamen kedinindir. Kedi hem suçlu hem suçsuzdur.
